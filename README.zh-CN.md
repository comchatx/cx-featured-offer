你的报价失去 Buy&nbsp;Box 时，cx 会查出原因，店铺里能改的在你允许的范围内直接改，不低于你定的底价；要你或亚马逊处理的，写成计划交给你。它需要 Amazon Listing Playbook、Amazon SP-API 和 Scheduled Tasks，「插件」页会一并安装。

你可以这样问：

- 每小时看一次 B0EXAMPLE1 的 Buy&nbsp;Box，丢了先别改价，告诉我原因。
- 守住 B0EXAMPLE2 和 B0EXAMPLE3 的 Buy&nbsp;Box，底价 19.99 美元，每天查两次。
- B0EXAMPLE1 是 FBA 发货，丢了 Buy&nbsp;Box 时提醒我补货。

cx 能直接改的是价格偏高、自配送报价库存不足这类问题；FBA 补货、账户状况申诉这类，要你或亚马逊处理。装了 Keepa 时，cx 还会看 Buy&nbsp;Box 的历史；装了 Feishu 时，cx 在飞书上告诉你，否则在对话里告诉你。你的要求会写成每条 listing 的指令，存在你的文件里，可以随时查看和修改。

## 费用

只有在 cx 的电脑开机时才会检查，你需要为开机时长和每次检查读取的数据付费。
