# A listing's standing instruction for its Buy Box

- The seller's standing instruction for guarding one listing's Featured Offer is the file `/tenant/listings/<ASIN>/featured-offer.md`, one file for each listing, under the listing's ASIN.
- The file holds the seller's own words for that listing.
- The file is in the seller's files: the seller can read it and change it.
- How Amazon picks the Featured Offer, and which causes a change can reach, is in `cx-listing-playbook`'s `featured-offer` skill.
